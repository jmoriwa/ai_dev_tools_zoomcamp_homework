# AI Dev Tools Zoomcamp

Homework projects share this Git repository, with each project in its own folder.

| Homework | Folder | Description |
| --- | --- | --- |
| 1 | [ai_dev_tools_zoomcamp_homework](ai_dev_tools_zoomcamp_homework/README.md) | Shared Household Chores Django app |
| 2 | [homework_2](homework_2/README.md) | Reserved for the second homework project |

Run each project's setup and development commands from its own folder. For homework 1:

```powershell
cd ai_dev_tools_zoomcamp_homework
```

Follow that folder's README for installation, running the app, and verification.

The root `.gitignore` applies to both projects. Keep project dependencies and
environments in their respective folders. Use the existing repository for future
homework folders as well; no additional `git init` is needed.
